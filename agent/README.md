# PrintSheba Windows Native Print Agent (প্রিন্ট সেবা উইন্ডোজ এজেন্ট)

সরাসরি উইন্ডোজের জন্য কম্পাইল করা **`PrintShebaAgent.exe`**—যা সাইবার ক্যাফে ও কম্পিউটার দোকানের পিসিতে ব্যাকগ্রাউন্ডে চালু থাকলে গ্রাহকের দেওয়া পেইড ফাইল কোনো মানুষের হস্তক্ষেপ ছাড়াই প্রিন্টারে সরাসরি প্রিন্ট হয়।

---

## 🌟 মূল সুবিধাসমূহ (Key Features)

1. **স্ট্যান্ডঅ্যালোন উইন্ডোজ এক্সিকিউটেবল (`.EXE`):**
   * কোনো Node.js, Python বা অতিরিক্ত রানটাইম ইনস্টল করতে হয় না।
   * ফাইল সাইজ মাত্র ~৩০ KB।
   * Windows 7, 8, 10 এবং 11 (32-bit ও 64-bit) এ সরাসরি চলে।
2. **স্বয়ংক্রিয় প্রিন্টার ডিটেকশন ও রাউটিং:**
   * কম্পিউটারে সংযুক্ত সব প্রিন্টার (Canon, Epson, HP, Brother) নিজে থেকে ডিটেক্ট করে।
   * **সাদাকালো প্রিন্টার:** বি/ডব্লিউ জবের জন্য নির্ধারিত প্রিন্টারে পাঠায় (যেমন Canon LBP 2900)।
   * **রঙিন প্রিন্টার:** কালার জবের জন্য নির্ধারিত প্রিন্টারে পাঠায় (যেমন Epson EcoTank L3210)।
3. **মাল্টি-ফরম্যাট সাইলেন্ট প্রিন্টিং:**
   * **ইমেজ (JPG, PNG, BMP):** কোনো উইন্ডো বা ডায়ালগ ছাড়াই নেটিভ GDI স্কেলিং সহ প্রিন্ট হয়।
   * **পিডিএফ (PDF):** উইন্ডোজ প্রিন্ট ড্রাইভারে ব্যাকগ্রাউন্ডে স্বয়ংক্রিয়ভাবে স্পুল হয়।
   * পেজ সংখ্যা ও কপি সংখ্যা স্বয়ংক্রিয়ভাবে নিয়ন্ত্রণ করে।
4. **জিরো-রিটেনশন প্রাইভেসি গার্ড (Zero-Retention Privacy):**
   * গ্রাহকের গোপনীয়তা রক্ষায় প্রিন্ট শেষ হওয়ামাত্রই `%TEMP%\PrintSheba\` ফোল্ডার থেকে লোকাল ফাইল স্থায়ীভাবে ডিলিট করে দেওয়া হয়।
5. **সিস্টেম ট্রে ও উইন্ডোজ অটো-স্টার্ট:**
   * মিনিমাইজ করলে ঘড়ির পাশে সিস্টেম ট্রেতে লুকিয়ে থাকে, টাস্কবারে ভিড় করে না।
   * কম্পিউটার চালু হলে নিজে থেকেই ব্যাকগ্রাউন্ডে চালু হতে পারে (Auto-start with Windows)।
6. **টেস্ট প্রিন্ট বাটন:**
   * এক ক্লিকেই প্রিন্টারের সাথে যোগাযোগ যাচাইয়ের জন্য টেস্ট পেইজ প্রিন্ট করার সুবিধা।

## 📁 ফাইল স্ট্রাকচার

* **`PrintShebaAgent.exe`** — প্রস্তুত এক্সিকিউটেবল ফাইল। ডাবল ক্লিক করলেই চলবে।
* **`PrintShebaAgent.cs`** — সম্পূর্ণ সি-শার্প (.NET) সোর্স কোড।
* **`build_exe.ps1`** — পাওয়ারশেল স্ক্রিপ্ট যা এক ক্লিকে কোড কম্পাইল করে `.exe` ফাইল তৈরি করে।
* **`config.json`** — কনফিগারেশন ফাইল (সার্ভার ইউআরএল ও শপ এপিআই টোকেন)।
* **`start-agent.bat`** — দ্রুত লঞ্চার ব্যাচ ফাইল।

## 🛠️ পুনরায় কম্পাইল করার নিয়ম (Recompilation)

যদি কোনো ফিচার পরিবর্তন বা কাস্টমাইজ করতে চান, শুধু পাওয়ারশেল থেকে চালান:

```powershell
powershell -ExecutionPolicy Bypass -File .\build_exe.ps1
```

এটি স্বয়ংক্রিয়ভাবে `PrintShebaAgent.exe` তৈরি করে এবং ওয়েবে ডাউনলোডের জন্য `public/downloads/` ফোল্ডারে কপি করে দেবে।
